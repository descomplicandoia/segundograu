Tutorial com o caminho mais curto para carregar um processo, subir um modelo de voto e elaborar a minuta — o suficiente para começar a usar hoje.

🕑 ~8 min de leitura 🖱️ 7 passos Acesso: minutaia.tjsp.jus.br

Resumindo o básico

Suba os documentos do processo pelo número → carregue seu modelo (da biblioteca, se já tiver salvo) → no Chat, ligue a Pesquisa jurídica → mude para Minuta, escreva a instrução para gerar a minuta e clique na seta.

Para lembrar sempre

  • Use Nova Minuta sempre que mudar de processo — isso limpa o contexto anterior.
  • Não misture documentos de processos diferentes na mesma conversa.
  • Chat serve para pensar, perguntar e resumir (sem limite). Minuta serve para redigir, revisar e finalizar (limite de 80 por mês).
  • Prefira instruções diretas e objetivas — evite prompts genéricos ou cheios de explicações de formatação.
  • Confira sempre fatos, valores, nomes, datas, legislação e jurisprudência antes de usar o resultado. A revisão humana é indispensável.
